# semenov/tap

Homebrew formulae for my tools:

- [ship](https://github.com/semenov/ship): deploy web apps to your own server with one command
- [homebase](https://github.com/semenov/homebase): run local dev servers as launchd agents, reachable at `<name>.localhost`
- [hangar](https://github.com/semenov/hangar): start, stop and open Claude Code Remote Control sessions from an iPhone app and a terminal UI

```sh
brew install semenov/tap/ship
brew install semenov/tap/homebase
brew install semenov/tap/hangar
```
